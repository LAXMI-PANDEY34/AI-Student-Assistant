 AI Student Assistant

📌 About Project

AI Student Assistant is a C++ based student management and study assistance project. It helps students manage their academic information and organize their study activities.

✨ Implemented Features

1. Student Report
   
   - Enter student details.
   - Enter subject marks.
   - Calculate total marks and percentage.
   - Calculate grade and pass/fail status.
   - Save and view student report.

2. Study Timetable
   
   - Create study timetable.
   - Save timetable.
   - View saved timetable.

3. AI Question Assistant
   
   - Basic question-answer assistance.
   - Keyword-based responses to study-related questions.

4. Study Planner
   
   - Add study tasks.
   - Manage task status.
   - Save and view study planner data.

5. File Handling
   
   - Store student reports in text files.
   - Save study timetable and planner data.

🛠️ Technology Used

- C++
- Object-independent functions
- File Handling ("fstream")
- Conditional Statements
- Loops
- Functions

📂 Project Files

- "mainfile.cpp"
- "student_report.txt"
- "study_timetable.txt"
- "study_planner.txt"
